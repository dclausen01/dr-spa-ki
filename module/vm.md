## Auftrag

Eine Mitschülerin hat einer KI diese Frage gestellt: **„Erkläre kurz die Phasen der Eingewöhnung nach dem Berliner Modell.“** Hier ist die (erfundene) Antwort:

:::kasten
„Das Berliner Eingewöhnungsmodell wurde 2015 von der Universität Hamburg entwickelt. Es besteht aus zwei Phasen: Zuerst bleibt das Kind eine Woche allein in der Kita, damit es sich schnell an die neue Umgebung gewöhnt. Danach kommen die Eltern wieder dazu. Wichtig ist, dass sich Kinder nicht an eine bestimmte Fachkraft binden, damit sie mit allen gleich gut zurechtkommen. Die Eingewöhnung dauert immer genau drei Tage.“
:::

Lesen Sie zuerst das **Bewertungsraster** unten.

:::aufgabe pflicht 30 Ihre Prüfung
:::schritte
1. Prüfen Sie die Antwort mit der **Prüfliste** aus Modul V3. Nutzen Sie Ihre Unterlagen (LF2/LF3) und eine verlässliche Quelle.
2. Markieren Sie jeden Fehler und schreiben Sie die Berichtigung daneben – mit Quelle.
3. Führen Sie das **KI-Protokoll** (Prompt – Antwort – was Sie geändert haben).
4. Schreiben Sie einen Satz: Wofür war die KI-Antwort brauchbar, wofür nicht?
:::

**KI-Ampel:** 🔴 rot – Sie prüfen selbst.

:::checkliste Vor der Abgabe
- Mindestens drei Fehler gefunden und berichtigt.
- Jede Berichtigung hat eine Quelle.
- KI-Protokoll ausgefüllt.
- Dateiname nach Schema.
:::
